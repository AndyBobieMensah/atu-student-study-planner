STUDENT STUDY PLANNER - BEGINNER PROJECT

FILES
1. index.html  - the structure/content of the website
2. style.css   - the visual design
3. script.js   - adding, completing, deleting, filtering and saving tasks

HOW TO OPEN
1. Extract this ZIP file.
2. Open the student_study_planner folder.
3. Double-click index.html.
4. The website should open in your web browser.

IMPORTANT
- Keep all three files in the same folder.
- Do not rename the files unless you also update the links in index.html.
- Tasks are saved in the browser's local storage on that device/browser.
- Clearing browser site data may remove the saved tasks.
